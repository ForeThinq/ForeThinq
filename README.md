**n8n/Make automations + AI integrations for businesses that run on leads.**

I build systems that catch every lead, qualify it, and follow up automatically — so nothing slips through while you're busy doing the actual work.

## What I build

- **Lead-flow automation** — capture → dedupe → AI classify & score → CRM/Sheets → instant alert → follow-up

- **AI data extraction** — forms, docs and invoices turned into clean Sheets/CRM rows; scraping & list cleanup with AI enrichment
- **Workflow fixes & rescues** — broken automations diagnosed, rebuilt, and monitored
